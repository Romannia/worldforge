# Worldforge

Worldforge is a writing tool for fantasy and sci-fi authors to plan, organize, and write their novels in one place, from chapters and scenes to characters, locations, and worldbuilding notes.

**Status:** Early development

**Note:** This is a study project with focus on React, TypeScript and testing. 

## Getting started

### Prerequisites

- Node.js (LTS)
- Git

### Installation

```bash
git clone https://github.com/Romannia/worldforge
cd worldforge
npm install
npm run dev
```
Open 'http://localhost:5173/' in the browser.
